Building a Shared Foundation

Fewer bug reports (~35%), consistent UI across modules, and a faster path from design to production.

2024

Client
Diageo Experience Center
Role
Product Designer
Duration
12 months
Year
2024

Overview

DxC was growing fast. New modules were planned, and users kept asking for simpler processes. The design team proposed building a shared component library before designing anything new.

New modules were coming. We needed a foundation, before new screens.

The challenge

The platform had grown screen by screen. Simple flows felt complex, and every new feature added more inconsistency.

We needed to pause and create something the team could design from, not around.

Listened first

User interviews and feedback analysis showed where flows broke down.

Proposed a plan

A redesign proposal with a component library and an execution timeline.

Built with engineering

Components were built in parallel with the frontend lead in Storybook.

Documented everything

Usage guidelines in Jira became a shared reference for the whole team.

Impact

Fewer bug reports (~35%), consistent UI across modules, and a faster path from design to production.

The library became the starting point for the platform-wide redesign that followed.

What I learned

A design system starts with alignment, not components. Building side by side with engineering made the library something the team actually used.

Next time, I'd bring developers in even earlier, from the first audit.
